# Contacts API

REST API for managing contacts using FastAPI, SQLAlchemy and PostgreSQL.

## Features

- Create contact
- Get all contacts
- Get contact by id
- Update contact
- Delete contact
- Search contacts
- Upcoming birthdays

## Technologies

- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn
